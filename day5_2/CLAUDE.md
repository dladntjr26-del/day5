# CLAUDE.md

## 기술 스택
- HTML
- Tailwind CSS
- JavaScript
- Lucide Icons

## 규칙
- 이 프로젝트는 HTML, Tailwind CSS, JavaScript, Lucide Icons로 웹페이지를 만든다.
- 사용자가 명시적으로 특정 API나 라이브러리를 사용하라고 하면 그대로 사용한다.
- 위 기술 스택 외에 필요한 API나 라이브러리가 있으면 반드시 사용자에게 먼저 확인을 받은 뒤 사용한다.
- 작업 중 문제가 발생하면 단순히 "안 된다"고 말하지 않고, 해결 방법을 함께 제시한다.

## 승인된 외부 서비스
- picsum.photos — 더미 이미지 (`https://picsum.photos/seed/{시드}/{가로}/{세로}`)
- Wikimedia Commons — 자유 라이선스 사진. 내려받아 `images/`에 저장하고, 라이선스에 맞게 출처를 표기한다.
